# TestLab project documentation

TestLab is a personal learning workspace first. Work through small tests in the browser, then practice real tools against the included TaskBoard application.

- [Getting started](getting-started.md): run TestLab and the separate practice project.
- [Your study plan](learning-plan.md): progress from your first assertion to a complete testing strategy.
- [Architecture](architecture.md): folders, execution boundaries, data, and infrastructure.
- [Testing and verification](testing.md): verify the application and the course examples.
- [Writing course content](curriculum-authoring.md): add lessons without breaking execution or progress.
- [Before a public release](release-checklist.md): current limitations and the work to do later.

Current course: **36 practical lessons**, **40 concept checks**, and **50 glossary terms**. Fourteen exercises run through TestLab’s restricted interpreter. Twenty-two guided labs run with real tools in `practice-project/` and use explicitly self-reported completion.
